================================================================================
         POVALY AUTO-UPDATE SYSTEM - QUICK START GUIDE
================================================================================

Your GitHub Repo: https://github.com/goimranx/povaly.git

================================================================================
STEP 1: PUSH CODE TO GITHUB (5 minutes)
================================================================================

Open Command Prompt in project folder:

    cd "d:\Work Area\Development\Projects\povaly"
    git init
    git add .
    git commit -m "Initial commit with auto-update system"
    git remote add origin https://github.com/goimranx/povaly.git
    git branch -M main
    git push -u origin main

If asks for credentials, go to Step 2 first.

================================================================================
STEP 2: CREATE GITHUB TOKEN (3 minutes)
================================================================================

1. Go to: https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Name: "Povaly Auto-Update"
4. Check: [✓] repo (all)
5. Click "Generate token"
6. COPY THE TOKEN! (starts with ghp_...)

Configure Git with token:

    git config credential.helper store
    git remote set-url origin https://YOUR_TOKEN@github.com/goimranx/povaly.git
    
Replace YOUR_TOKEN with actual token from GitHub.

Example:
    git remote set-url origin https://ghp_abc123xyz@github.com/goimranx/povaly.git

Test it:
    git fetch origin main

================================================================================
STEP 3: RUN SETUP SCRIPT (2 minutes)
================================================================================

Double-click this file:
    setup-update-system.bat

Or run in Command Prompt:
    cd "d:\Work Area\Development\Projects\povaly"
    setup-update-system.bat

This will:
- Clear all caches
- Register routes
- Test Git connection
- Verify all files exist

================================================================================

================================================================================

URL: http://povaly.com/pv-admin/system-update

Menu: Platform Admin → System → System Update

You should see:
- Current Version info
- 4 buttons: Check Updates, Update Now, Force Update, Clear Cache

================================================================================
WHAT EACH BUTTON DOES
================================================================================

Check for Updates:
    - Checks GitHub for new commits
    - Shows what changed
    - Safe, doesn't modify anything

Update Now:
    - Full system update (2-5 minutes)
    - Pulls code, updates packages, compiles assets
    - Site in maintenance mode during update

Force Update:
    - Updates even without Git changes
    - Rebuilds everything
    - Use when Git is out of sync

Clear Cache Only:
    - Just clears caches (10-20 seconds)
    - No Git operations
    - Quick fix for cache issues
